# Object-Oriented Programming with Java

A Java project developed as part of my Object-Oriented Programming studies, containing practical exercises focused on Java fundamentals and the main concepts introduced throughout the course.

## Overview

This repository contains a collection of Java exercises developed during my studies of Object-Oriented Programming.

The activities are organized by topic, allowing each concept to be practiced independently while building a solid foundation in Java.

The current exercises cover:

- **Java Fundamentals** — basic program structure and syntax
- **Type Conversion** — converting primitive values to strings
- **Operators** — mathematical and arithmetic operations
- **User Input** — reading and processing data with `Scanner`
- **Strings** — working with string length and individual characters
- **Arrays** — storing and processing multiple values

As the course progresses, new exercises and Object-Oriented Programming concepts will be added to the repository.

## Features

- Practical Java exercises organized by topic
- Simple and focused examples for each concept
- Console-based applications
- Use of Java's standard library
- Progressive introduction to Object-Oriented Programming concepts
- Exercises developed as part of university coursework

## Topics Covered

### Java Fundamentals

Introduction to Java syntax, program structure, variables, primitive data types, and console output.

### Type Conversion

Practice with converting primitive data types into `String` values using Java's standard methods.

### Operators

Exercises involving:

- Addition
- Subtraction
- Multiplication
- Division

### User Input

Working with the `Scanner` class to receive and process information entered by the user.

### Strings

Basic string manipulation, including:

- String length
- Accessing characters
- First and last character extraction
- String concatenation

### Arrays

Using arrays to store multiple values and process collections of data.
